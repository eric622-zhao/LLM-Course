# 周报生成

## 什么时候用

用户提供零散的工作内容（聊天记录、提交列表、随手记的要点），并希望得到一份可以直接发出的周报时。

## 步骤

1. **先收集素材**。如果用户没给内容，但当前目录是个 git 仓库，可以用
   `RunCli(command="git", args=["log", "--since=1 week ago", "--pretty=format:%h %s", "--author", "<用户名>"])`
   取本周提交作为素材。
2. **归类**。把素材拆进三个固定板块，宁缺毋滥：
   - 本周产出：动词开头的短句，每条不超过 40 字，能写数字就写数字（"重构 3 个接口"好于"做了重构"）。
   - 问题与风险：只写**还没解决**的；已解决的放到产出里。
   - 下周计划：写"要交付什么"，不写"要研究什么"。
3. **排版**。标题用 `##`，每条用无序列表；不要写开场白和客套话，不要编造没发生的成绩。
4. **自检**。发出前检查：有没有把"参与"写成"负责"？有没有无法验证的形容词（显著、大幅）？

## 输出格式

```markdown
## 本周产出
- …

## 问题与风险
- …（没有就写"无"）

## 下周计划
- …
```
