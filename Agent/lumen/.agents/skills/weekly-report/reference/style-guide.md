# 周报排版细则

## 句子

- 一条只说一件事。出现"并且""同时"就考虑拆成两条。
- 动词开头，不写"完成了……的工作"这类空心结构。
- 能量化就量化：数量、百分比、耗时、覆盖范围。
- 不写"积极配合""大力推进"这种无法验证的词。

## 数字

- 用阿拉伯数字（3 个、12 次），不用"三个""十几次"。
- 时间写区间不写"最近"：写"10 月 28 日—11 月 1 日"。

## 层级

- 最多两级：`## 板块` + `- 条目`。不要再往下嵌套。
- 板块顺序固定：产出 → 问题与风险 → 下周计划。

## 反面例子

| 不要写 | 改成 |
| --- | --- |
| 积极参与了项目的开发工作 | 完成登录模块的接口联调，覆盖 4 个场景 |
| 大幅提升了系统性能 | 列表接口 P95 从 820ms 降到 190ms |
| 下周继续跟进相关事项 | 下周交付导入功能，11 月 8 日前可验收 |
