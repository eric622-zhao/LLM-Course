# 改完代码后的测试自检

## 适用场景

修改 `core/` 下的代码后，提交或回复用户之前，必须确认测试已跑通。

## 必跑命令

按顺序执行以下两条命令：

1. 单元测试：

   ```bash
   py -m unittest discover -s tests -v
   ```

   要求：全部用例通过，不能有 error 或 failure。

2. 冒烟测试：

   ```bash
   py smoke_tui.py
   ```

   要求：TUI 能正常启动并可正常退出，无报错堆栈。

## 注意事项

- 两条命令缺一不可，不能只跑其中一条。
- 命令失败时先定位原因并修复，再重新完整跑一遍，不要只重跑失败的部分就宣称通过。
- 禁止为了让测试通过而放宽安全校验（路径边界、删除确认、密钥检查）。
- 自检的具体条目见附件 `checklist.md`，逐条核对后再收尾。
