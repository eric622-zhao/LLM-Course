# 流明 Lumen · 项目规则

> 这个文件会在启动时被读取并注入 System Prompt，作为本项目的长期约定。
> 想关掉：`config.ini` 的 `[agent] rules_enabled = false`。

## 代码约定

- 工具函数**失败时返回以「错误：」开头的字符串，不抛异常**。
  模型要靠这句话判断「该换参数、换方案，还是如实告诉用户」，抛异常会直接中断整轮对话。
- 路径类操作一律经过 `realpath` + `commonpath` 校验，不得越出项目根目录。
- 删除、覆盖这类不可恢复操作，执行前必须先向用户确认。
- 注释与面向用户的文案用中文；标识符用英文。

## 回答风格

- 中文回答，先给结论再给依据；不要复述大段原文，需要引用时只摘关键句。
- 涉及文件时用「相对项目根目录」的路径，例如 `core/agent.py`，不要贴整条绝对路径。
- 不确定就说不确定，不要编造 API、函数名或文件内容。

## 改动纪律

- 修改 `core/` 下的代码后，至少运行：
  - `py -m unittest discover -s tests -v`
  - `py smoke_tui.py`
- **不要修改 `config.ini`**（里面有真实密钥）。需要新配置项就加到 `config.example.ini`，
  并同步更新 README 的配置说明。
- 新增或改名工具时，同步更新 README 里的工具清单 —— 文档与代码不一致是本项目的重点扣分项。

## 禁止事项

- 不要为了让测试通过而放宽安全校验（路径边界、删除确认、密钥检查）。
- 不要把 `.lumen/`（会话与追踪）或 `__pycache__` 提交进仓库。
